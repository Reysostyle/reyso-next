# ReySo — Next.js Rebuild (فاز ۱: پایه + هوم‌پیج)

## اجرا
```bash
npm install
npm run dev
```
بعد `http://localhost:3000` رو باز کن.

## چیزی که تو این فاز ساخته شده
- پایه‌ی پروژه: Next.js 15.5.21 (patched)، TypeScript، Tailwind v4
- RTL کامل + دیزاین توکن‌های برند (سبز #1C4436 / طلایی #AD9155)
- فونت‌های Vazirmatn و Noto Naskh Arabic، هر دو self-hosted و تست‌شده
- هدر sticky + بخش Hero با گرید نامتقارن و افکت reveal پارچه‌ای (Framer Motion)

## فازهای بعدی (پیشنهادی)
- بخش دسته‌بندی محصولات (بنتو گرید مشابه نسخه‌ی وانیلا)
- کارت محصول + صفحه‌ی shop
- فوتر + نیوزلتر
