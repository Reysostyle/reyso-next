# فونت‌های برند

## ✅ Vazirmatn — فونت متن
`Vazirmatn-Variable.ttf` self-hosted در همین پوشه (طبق Design System v1.0،
چون CDN گوگل از ایران قابل‌اعتماد نیست).

## ✅ Mirza — فونت نمایشی/تیترها
دیگه از Noto Naskh Arabic استفاده نمی‌شه. Mirza یه فونت calligraphic با الهام
از خط نستعلیق فارسیه — خاص‌تر و متمایزتر. به‌جای فایل دستی، از پکیج
`@fontsource/mirza` (در package.json) میاد؛ همچنان کاملاً self-hosted و
بدون نیاز به فراخوانی CDN گوگل در زمان اجرا.
